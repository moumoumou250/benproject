# 匿名未授权访问管理后台配置接口 `/rest/admin/application-configuration`

**ID:** vuln-0001
**Severity:** HIGH
**Found:** 2026-11-02 13:19:44 UTC
**Target:** http://117.72.199.2:3000
**Endpoint:** /rest/admin/application-configuration
**Method:** GET
**CVSS:** 7.5
**Confidence:** High
**Fix Effort:** Low

## Description

`GET /rest/admin/application-configuration` 在未登录状态下返回完整的 Juice Shop 管理后台配置 JSON，包括 Google OAuth clientId、CTF 挑战配置、产品评论列表、用户 Memories 以及地理跟踪安全问题的答案。

## Evidence

服务器返回 200 OK，Content-Type 为 `application/json; charset=utf-8`，Content-Length 约 23577。响应片段包含：
```json
{"googleOauth":{"clientId":"1005568560502-6hm16lef8oh46hr2d98vf2ohlnj4nfhq.apps.googleusercontent.com",...}}
```
以及：
```json
{"geoStalkingMetaSecurityAnswer":"Daniel Boone National Forest"}
```

## Impact

该接口泄露了大量管理员级敏感信息，攻击者可直接获取：
1. Google OAuth 客户端 ID（`1005568560502-6hm16lef8oh46hr2d98vf2ohlnj4nfhq.apps.googleusercontent.com`），可用于进一步的 OAuth 攻击面分析。
2. 地理跟踪安全问题的标准答案：`Daniel Boone National Forest` 和 `ITsec`，可用于账户接管或密码重置绕过。
3. 内部挑战配置、CTF 标志、CSAF 哈希值等运营敏感数据。
4. 产品评论中暴露的内部测试用户名（admin、uvogin、basil、rapper 等），为后续社会工程或凭证填充提供素材。

## Counterevidence

未发现该端点存在任何授权中间件或角色校验。返回的 JSON 中不包含时间戳或一次性令牌等动态防护字段。

## What Would Change This Severity

若该接口实际部署在生产环境前端网关后且网关已做 IP 白名单限制，则严重程度可能降低。

## Technical Analysis

该端点预期仅对管理员或已认证用户开放，但实际未执行任何会话或角色校验。响应头中包含 `Access-Control-Allow-Origin: *`，使得任意第三方网站可通过浏览器跨域请求直接读取该配置，进一步放大了信息泄露的风险。响应体大小约 23 KB，内容完整。

## Proof of Concept

1. 在未携带任何 Cookie 或认证凭据的情况下，直接发送 GET 请求至 `/rest/admin/application-configuration`。
2. 服务器返回 HTTP 200，响应体为包含完整管理配置的 JSON。

```http
GET /rest/admin/application-configuration HTTP/1.1
Host: 117.72.199.2:3000
User-Agent: Mozilla/4.0 (compatible; MSIE 7.0; Windows NT 10.0; WOW64; Trident/7.0; .NET4.0C; .NET4.0E; Tablet PC 2.0)
Accept: */*
Accept-Language: zh-CN
Accept-Encoding: gzip, deflate
Connection: close
Cache-Control: no-cache
```

## Remediation

在 `/rest/admin/application-configuration` 端点增加严格的身份认证与授权校验，确保仅管理员角色可访问。同时审查 CORS 配置，避免将管理接口的响应暴露给任意来源。

## Assumptions

假设攻击者可通过直接网络访问该目标。
