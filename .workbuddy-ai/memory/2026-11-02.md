### 修复的真实缺陷（Ben/agents/factory.py 授权白名单闸门）
1. **文件名被误判为域名**：`python main.py`、`cat notes.txt`、`nmap -oX out.xml`、
   `python3 -m http.server` 全部被拒（"未授权目标 ['main.py']"）。修复：新增
   `_extract_hosts(net_context=)`，命令未调用网络客户端时只提取 URL/IPv4，不把裸点号
   token 当域名；`-oX/-oG/-iL` 等文件参数的下一个 token 跳过。
2. **`-D` 被当成 `-d`**：`curl -D -`（dump-header，只读）因 `_PAYLOAD_FLAG_RE` 大小写
   不敏感被误拒。修复：短标志 `-d/-F/-T` 改为大小写敏感，长标志 `--data/--form/...`
   仍不敏感；`-X` 同理（`-x` 是代理）。
3. **`ssh user@host` 的 userinfo 未剥离**：`ssh user@evil.com` 被放行。修复：token 内
   有 `@` 时取 `rsplit("@",1)[1]` 再判域名。
4. `_NET_CLIENT_RE` 由 `\b` 改为「后接分隔符或行尾」，并扩充到 nmap/ping/dig/ssh/nikto
   等 30+ 网络客户端（覆盖面扩大，同时消除 `http.server` 误判）。

新增 `tests/test_whitelist_gate.py`（37 个用例，全部通过）覆盖放行/拒绝矩阵。

### 本轮额外修复
1. **parametrize id 超 Windows 环境变量上限**：`OVER_NESTED`（十万字符 `[[[[...`）
   作为参数值时，pytest 自动生成的 test id 被写进 `PYTEST_CURRENT_TEST`，
   触发 `ValueError: the environment variable is longer than 32767 characters`（4 个 ERROR）。
   修复：给 `test_tool_call_arguments.py` / `test_agent_factory_tool_arguments.py`
   的这两个 `parametrize` 加显式短 `ids=`。
2. **测试进程每次都联网拉 LiteLLM 价格表**：`raw.githubusercontent.com` 读超时 ×3 次重试，
   整套测试凭空多花数分钟且不稳定。修复：`tests/conftest.py` 在 import litellm 前
   `os.environ.setdefault("LITELLM_LOCAL_MODEL_COST_MAP", "True")`，改用随包本地表。
3. **`test_pricing::test_resolves_common_bare_model_names` 数据漂移**：硬编码
   `grok-4.5` 假设「各 provider 同价」，但 LiteLLM 新增 `kyma/grok-4.5`
   （2.73e-06/8.189e-06，与 xai 的 2e-06/6e-06 不同价），解析器按设计返回 None。
   生产行为正确（宁可不报价也不猜价），改为从实时价格表挑选候选：
   `_pick_bare_name(agree=True/False)`，新增「provider 异价时必须返回 None」的用例。
   现状：150 个 bare 名字同价可解析，277 个异价返回 None。

### 关键约定（后续维护须知）
- 测试不得依赖 `Ben/config/__init__.py` 的立即导入，`models` 是惰性导出的

  跑全量时不要误判为卡死
